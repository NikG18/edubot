# Юридические документы сервиса

Актуальная рабочая редакция: **29.08.2026**.

Публичные документы в этой папке используются ботами как неизменяемые версии для показа пользователям и репетиторам. Код хранит тип документа, версию и SHA-256 текста в `legal_acceptances`.

## Яндекс Форма для репетитора

Первичная анкета репетитора должна содержать идентификационные данные (ФИО, ИНН, статус ИП/НПД, контакты, Telegram/VK, анкету, предметы/цены и данные для карточки) и **три отдельных юридических блока**:

1. Акцепт агентского договора — отдельное обязательное действие со ссылкой на `01_agent_agreement.md`.
2. Согласие на обработку ПД — отдельное действие со ссылкой на `04_tutor_pd_consent.md`.
3. Согласие на распространение ПД — отдельный блок со ссылкой на `05_tutor_distribution_consent.md`, без заранее выбранных ответов и с отдельным выбором категорий данных и площадок.

Для каждого ответа нужно сохранять идентификатор ответа формы, дату/время, ФИО/ИНН, редакцию документа и конкретный результат. Для согласия на распространение нужно сохранять не общий флаг, а выбранный набор категорий/площадок.

Функция `legal_common.record_tutor_yandex_acceptance(...)` предназначена для записи этих подтверждений в `legal_acceptances` после импорта ответа формы. Сам способ импорта (ручной админ-импорт, выгрузка или API/webhook) выбирается отдельно после определения фактической интеграции с Яндекс Формами.

## Публикация

В production `LEGAL_DOCS_BASE_URL` по умолчанию указывает на `https://github.com/NikG18/edubot/blob/main/legal`. До слияния ветки для smoke-теста можно временно задать:

`LEGAL_DOCS_BASE_URL=https://github.com/NikG18/edubot/blob/feature/legal-documents/legal`
